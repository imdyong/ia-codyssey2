# Project-A_UI-UX
AI 기반 UI/UX 디자인 시안 제작 프로젝트 진행

# 프로젝트 개요
- 웹페이지 이름: 꽃갈피 (Flower Bookmark)
- 목적: 꽃 이름을 검색하거나 꽃 사진을 선택하여 꽃말, 개화 시기, 특징, 관리 방법 등의 정보를 제공하는 꽃 정보 아카이빙 서비스
- 디자인 컨셉: 압화(눌러 말린 꽃) 표본집과 책갈피 리본을 모티브로 한 감성적인 모바일 앱 스타일 (크림 페이퍼 배경과 보태니컬 디자인 적용)

# 핵심 기능 및 화면 구성 가이드

## 1. 메인 홈 화면
- 상단: 리본 모양 로고와 '꽃갈피' 워드마크, 프로필 아이콘
- 점선 테두리 검색창 제공
  * 꽃 이름 검색
  * 검색 결과 실시간 표시
- 오늘의 꽃 추천 카드
  * 대표 꽃 이미지
  * 꽃 이름
  * 꽃말 한 줄 소개
  * [자세히 보기] 버튼
- 계절별 꽃 추천
  * 봄
  * 여름
  * 가을
  * 겨울
- 인기 꽃 카드
  * 꽃 이미지
  * 꽃 이름
  * 표본번호
  * 저장 버튼
- 하단 고정 네비게이션 바(GNB)
  * 홈
  * 마이페이지

---

- 최근 본 꽃 개수
- 저장한 꽃 목록
- 최근 본 꽃 목록
- 하단 네비게이션 바(GNB)

# 주요 기능

- 꽃 이름 검색
- 실시간 검색 결과 표시
- 꽃 상세 정보 조회
- 꽃말 확인
- 개화 시기 확인
- 즐겨찾기(책갈피) 저장
- 최근 본 꽃 확인
- 계절별 꽃 추천

# 디자인 시스템

### Color

- Background : Cream Paper (#F6EFDF)
- Card : #FCF9F0
- Primary : Deep Green (#3F5539)
- Accent : Terracotta (#B97A5D)
- Accent Gold : #B08A34
- Border : #DCD1B4
- Text : #2B2620

### Typography

- 제목 : Serif
- 본문 : Sans Serif
- 표본번호 및 학명 : Monospace

### Component

- 점선 카드 스타일
- 리본(BookMark) 태그
- 보태니컬 일러스트
- 재사용 가능한 카드 컴포넌트

# 수정 사항

### 초안
- 기본 꽃 정보 UI 생성
- 메인 화면 구성
- 꽃 상세 화면 구성
- 마이페이지 구성

### 수정
- 검색창을 실제 입력 가능한 Input Field로 변경
- 꽃 이름 실시간 검색 기능 추가
- 검색 결과 카드 구현
- 검색 결과 없음 화면 추가
- 검색 결과 클릭 시 꽃 상세 화면 이동
- 기존 디자인은 유지하면서 검색 기능 개선
