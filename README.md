# Project-A_UI-UX
AI 기반 UI/UX 디자인 시안 제작 프로젝트 진행

# 프로젝트 개요

- **웹페이지(앱) 이름:** 꽃갈피 (Flower Bookmark)
- **목적:** 꽃 이름을 검색하거나 꽃 사진을 선택하여 꽃말, 개화 시기, 원산지, 특징 및 관리 방법 등의 정보를 제공하고, 관심 있는 꽃을 책갈피에 저장할 수 있는 꽃 정보 아카이빙 서비스
- **디자인 컨셉:** 압화(눌러 말린 꽃) 표본집과 책갈피(BookMark)를 모티브로 한 감성적인 모바일 앱 스타일

---

# 핵심 기능 및 화면 구성 가이드

## 1. 메인 홈 화면

- 상단
  - 리본(BookMark) 형태의 로고
  - "꽃갈피" 워드마크
  - 프로필 아이콘
- 검색
  - 실제 입력 가능한 검색창(Input)
  - 꽃 이름 및 꽃말 검색
  - 검색어 삭제(X 버튼)
  - 실시간 검색 결과 표시
- 오늘의 꽃
  - 꽃 이미지
  - 꽃 이름
  - 꽃말
  - 자세히 보기 버튼
- 계절별 꽃 추천
  - 봄
  - 여름
  - 가을
  - 겨울
- 인기 꽃
  - 꽃 이미지
  - 꽃 이름
  - 표본번호
  - 저장(책갈피) 버튼
- 하단 고정 네비게이션(GNB)
  - 홈
  - 마이페이지

## 2. 꽃 상세 화면

- 상단
  - 뒤로가기 버튼
  - "꽃 상세" 제목
  - 북마크 버튼
- 꽃 정보
  - 꽃 이미지
  - 꽃 이름
  - 학명
  - 꽃말
  - 개화 시기
  - 원산지
  - 색상
  - 향기

- 하단

  - 저장 상태 토글

- 최근 본 꽃 목록

# 프로젝트 결과

AI를 활용하여 모바일 UI를 생성하고, Figma Make를 이용해 실제로 동작하는 프로토타입을 구현하였다.

검색 기능, 꽃 상세 정보, 책갈피 저장 기능, 화면 전환을 구현하여 사용자가 자연스럽게 꽃 정보를 탐색할 수 있는 UX를 설계하였다.
